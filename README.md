# Sovereign-Control-Panel-private-preview
Private preview onboarding documentation for Sovereign Control Panel 
# Overview
Sovereign Control Panel (SCP) is a new Azure sovereignty posture control centre that provides transparency, control, and confidence to help organisations meet sovereignty and compliance requirements. 

It offers a single unified view – a “single pane of glass” – showing where your organisation stands in terms of data sovereignty and regulatory compliance across your Azure estate.  

**SCP is currently in an invite-only Private Preview (Phase 1)**. 
This guide is designed for customer onboarding to that preview, Phase 1 focuses on the View Experience – the capability to create and view Sovereign Compliance “Views” across your Azure environment. In Phase 1, SCP is read-only: it does not create or modify cloud resources, making it a safe, observational tool for compliance monitoring. This guide will walk you through the offerings, key concepts and roles, and the step-by-step tasks needed to set up a Sovereign View and start seeing results.

We prefer support requests, feedback or bugs against the private preview features to be emailed to XXXXXX or provided directly to your Microsoft contacts, however we will also accept bugs and feedback filed using GitHub Issues.

**SCP Private Preview (Phase 1)** emphasises posture visibility: it helps you monitor existing Azure resources (“brownfield” environments) for compliance signals without making any changes to them 

Sovereign View (Preview) – a new Azure resource type in REM used to define what you want to monitor for sovereignty compliance. Creating a Sovereign View allows you to select a scope of Azure resources (e.g. a specific subscription, group of subscriptions, or a management group hierarchy) and a set of sovereign control signals (policy-based initiatives) to assess. The result is a tailored compliance view for that scope, shown in the Azure portal.
