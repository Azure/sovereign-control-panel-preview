# Support

## How to file issues and get help

For Sovereign Control Panel Private Preview support requests, bug reports, feature
requests, and feedback, contact your Microsoft product team or account
representative. You can also use
your existing Microsoft Teams channel for the preview.

Before requesting assistance, review the
[troubleshooting and support guide](docs/how-to/07-troubleshooting-and-support.md)
for common onboarding issues and known preview limitations.

Do not report security vulnerabilities through public GitHub issues. See
[SECURITY.md](SECURITY.md) for security reporting guidance.

## Microsoft Support Policy

Support for this project is limited to the resources listed above. Private Preview
support is currently limited to targeted customers participating in the preview.
