# Contribution policy

This repository is maintained exclusively by the internal Sovereign Control Panel (SCP) team (`@Azure/scp-team`). External contributions, including pull requests, are not accepted.

## Internal SCP contributors

Coordinate changes with the SCP team and submit pull requests for SCP team review. Only authorized SCP team members may merge changes. Do not publish confidential material, credentials, or customer data.

## Support and feedback

For support requests, feedback, and bug reports, reach us using the [support contact](https://learn.microsoft.com/en-us/azure/azure-sovereign-clouds/public/sovereign-control-panel) rather than submitting a pull request.

Do not report security vulnerabilities in public issues or pull requests. Follow [SECURITY.md](SECURITY.md).

## Enforcement

This document states the contribution policy; it does not enforce GitHub permissions or prevent external users from opening pull requests. Repository administrators must configure and verify branch rules and access permissions so that only `@Azure/scp-team` can merge changes, with no non-SCP bypass actors.
